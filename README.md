## ✨ Overview

SUB Config Decoder یک ابزار سبک و قدرتمند برای پردازش Subscriptionهای VPN است که تمام عملیات را **داخل مرورگر (Client-Side)** انجام می‌دهد.

- بدون بک‌اند  
- بدون ذخیره‌سازی دیتا  
- بدون ارسال اطلاعات  
- فقط سرعت و کنترل کامل

---

## 🔓 Features

### 🧠 Smart Decode Engine
- Decode خودکار Base64
- پشتیبانی از ورودی چندخطی
- تشخیص هوشمند پروتکل‌ها:
  - `vmess://`
  - `vless://`
  - `trojan://`
  - `ss://`

---

### 🧬 VMESS Decoder
- Decode واقعی VMESS (Base64 → JSON)
- نمایش ساختاریافته:
  - Server
  - Port
  - UUID
  - TLS / Security
  - Network Type

---

### 🔍 Live Search & Filter
- جستجوی لحظه‌ای (Real-time)
- فیلتر بدون نیاز به دکمه
- عملکرد سریع حتی روی لیست‌های بزرگ

---

### 🗂 Protocol Tabs
فیلتر سریع بر اساس نوع کانفیگ:

- VMESS
- VLESS
- Trojan
- Shadowsocks

---

### 📊 Statistics Panel
نمایش لحظه‌ای تعداد کانفیگ‌ها:

- Total Configs
- VMESS
- VLESS
- Trojan
- SS

## 🧰 How To Use

1. فایل `index.html` را دانلود کن
2. در مرورگر باز کن
3. یکی از موارد زیر را وارد کن:
   - Subscription Link
   - Base64
   - Raw Configs
4. روی **Generate** کلیک کن
5. فیلتر کن، Export بگیر 😎
